# LEISURE HOMME 出貨印單助手

把同一筆蝦皮訂單的寄件單與裝箱單排在一起，方便列印、包貨。**完全免費，以後也不會收費。**

[從 Chrome 商店安裝](https://chromewebstore.google.com/detail/pallcldjfgojcnbcnkmcpibhfpnkkfgf)

目前版本：**v0.11.11**｜[更新紀錄](CHANGELOG.md)

## 使用方式

1. 前往蝦皮「批次出貨 → 下載出貨文件」，點「印」字圖示開啟助手。
2. 確認訂單，勾選「寄件單」與「裝箱單」，裝箱單選「PDF」，不要勾選「撿貨單」。
3. 寄件單選「熱感列印」；7-ELEVEN、全家不需選此格式。
4. 按「下載所選文件」，等待助手完成，再按「預覽文件」列印。

紙張選 **100 × 150 mm**，自訂縮放 **125%**。第一次請少量試印，確認內容、條碼與尺寸。不同物流請分開下載。

## 支援物流

| 狀態 | 物流 |
| --- | --- |
| 支援 | 蝦皮店到店、隔日到貨、店到家宅配、7-ELEVEN、新竹物流、全家 |
| 測試中 | 無包裝隔日到、萊爾富、黑貓宅急便、嘉里快遞 |
| 尚未支援 | 其他寄送方式 |

一般列印及未支援的物流，請使用蝦皮原本的下載方式。
