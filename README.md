# LEISURE HOMME 出貨印單助手

Chrome 擴充功能，協助蝦皮台灣賣家在批次出貨頁下載並整理寄件單與裝箱單。

## 安裝

1. 到本專案的 **Releases** 下載 `shopee-shipment-print-helper-0.8.15.zip`。
2. 解壓縮到一個固定資料夾，安裝後保留該資料夾。
3. 在 Chrome 開啟 `chrome://extensions/`，開啟「開發人員模式」。
4. 按「載入未封裝項目」，選擇含有 `manifest.json` 的資料夾。
5. 重新整理蝦皮台灣批次出貨頁，即可使用。

GitHub 版本使用上述手動安裝方式，尚未在 Chrome 線上應用程式商店上架。

## 使用

在蝦皮「批次出貨 → 下載出貨文件」選擇訂單，同時勾選「寄件單」與「裝箱單」，按「下載所選文件」。助手會在背景讀取蝦皮文件、完成逐筆配對，顯示「文件已完成」後按「列印」。單獨勾選其他文件時仍使用蝦皮原生下載。

- 寄件單保留原始內容、位置和紙張尺寸。
- 每筆寄件單後接該筆裝箱單，列出貨號、規格、數量及買家備註。
- 裝箱單使用 100 × 150 mm；已預先縮為 80%，適用目前以 **125% 自訂縮放** 的列印方式。列印前請核對紙張、方向與預覽；其他縮放設定可能使內容偏小。
- 開啟時會先選取目前頁面的訂單；請確認訂單範圍。文件勾選仍由使用者決定。
- 任務顯示台灣時間的開始日期與時間。
- 任務只留在目前頁面的記憶體，重新整理即清空；「清除所有任務」也會取消處理中的任務。

## 支援範圍與限制

目前以 LEISURE HOMME 的蝦皮文字型裝箱單格式驗證。缺少主貨號時，僅支援 `TS13_BLK_L` 這類「兩碼英文字母＋兩碼數字_顏色_尺寸」格式；其他店家的貨號方式未必適用。掃描圖片、無法唯一配對的文件、跨原始頁的單笔訂單及不同物流版型可能需調整。資料不完整時會停止產生，請核對原始文件。

已通過自動測試與 Chrome 文件合併實測；未涵蓋所有物流商、作業系統及實體印表機。

點助手圖示直接開啟助手。在其他蝦皮頁面，助手內會顯示前往提示，點「[批次出貨 → 下載出貨文件](https://seller.shopee.tw/portal/sale/mass/ship?mass_shipment_tab=301)」即可到正確頁面，不再顯示額外選單。從其他蝦皮頁面切換過來也能使用；舊分頁尚未連線時會嘗試補載入。在蝦皮以外的頁面點圖示，或補載入失敗時，會開啟正確出貨頁。

## 開發及檢查

需要 Node.js 24 以上版本：

```sh
npm ci --ignore-scripts --omit=optional
npm test
npm run check
npm run package
```

測試資料已去識別化，不包含買家姓名、地址、電話或真實訂單編號。不要在 Issues 上傳原始寄件單、買家資料或登入資訊。
