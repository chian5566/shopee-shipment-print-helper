# LEISURE HOMME 出貨印單助手

**此工具已上架 Chrome 線上應用程式商店，請直接前往[安裝](https://chromewebstore.google.com/detail/pallcldjfgojcnbcnkmcpibhfpnkkfgf)。**

幫蝦皮賣家把同一筆訂單的寄件單與裝箱單排在一起，方便列印、包貨。

**完全免費，以後也不會收費。蝦皮 PDF 僅支援熱感列印；7-ELEVEN、全家使用原生寄件單。**

目前版本：**v0.11.10**。新增功能與修正請見 <a href="CHANGELOG.md" target="_blank" rel="noopener noreferrer">更新紀錄</a>。

## 操作提示

下載文件頁面顯示浮動編號氣泡：勾選訂單 → 熱感列印 → PDF → 下載所選文件。已完成的步驟顯示藍色勾號；物流未提供的格式會自動略過，尚未勾選文件則先提醒勾選寄件單／裝箱單。7-ELEVEN 寄件單勾選後保留第二步與完成勾號；文件選項排列緊密時，提示會改放在勾選框側邊。氣泡不影響原排版，也不攔截滑鼠點擊。

萊爾富版面研究參考：[蝦皮官方出貨手冊（2020，頁 21 的四格列印示意）](https://cdngarenanow-a.akamaihd.net/shopee/seller/seller_cms/7e6ee99bb562f0a699cf0b5580cf867d/%E8%90%8A%E7%88%BE%E5%AF%8C%E8%B6%85%E5%95%86%E7%89%A9%E6%B5%81%E5%87%BA%E8%B2%A8%E6%89%8B%E5%86%8A.pdf)。舊手冊僅作試作版面依據，不代表已確認現行單據相同。

## 安裝

請直接從 [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/pallcldjfgojcnbcnkmcpibhfpnkkfgf) 安裝，後續由 Chrome 自動更新。

### 手動安裝（進階）

1. <a href="https://github.com/chian5566/shopee-shipment-print-helper/releases/download/v0.11.10/shopee-shipment-print-helper-v0.11.10.zip" target="_blank" rel="noopener noreferrer">下載 v0.11.10 安裝檔</a>（`shopee-shipment-print-helper-v0.11.10.zip`），下載後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions/`，開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」，選擇解壓縮後的資料夾（裡面要有 `manifest.json`）。
4. 重新整理蝦皮頁面，即可使用。安裝後請保留這個資料夾。

更新時，換成新版檔案，到同一個擴充功能頁面按助手的重新載入按鈕，再重新整理蝦皮頁面。

## 設計原則

本工具開放給所有蝦皮賣家使用。商品貨號、規格、顏色、尺寸與名稱均視為賣家自訂文字，不以 LEISURE HOMME 的商品編碼或品類推算資料。商品列、數量與訂單配對依蝦皮文件的欄位、座標及原始識別資訊處理；品牌名稱與作者贊助連結僅供顯示，不參與資料判斷。

## 使用

1. 前往蝦皮 <a href="https://seller.shopee.tw/portal/sale/mass/ship?mass_shipment_tab=301" target="_blank" rel="noopener noreferrer">批次出貨 → 下載出貨文件</a>。
2. 點「印」字圖示開啟助手，再點一次可關閉；確認要出貨的訂單（助手會先選取目前頁面的訂單）。
3. 同時勾選「寄件單」與「裝箱單」，寄件單選「熱感列印」（7-ELEVEN、全家使用原生寄件單，不需選此格式）。
4. 按蝦皮的「下載所選文件」。
5. 助手顯示「文件已完成，可預覽」後，按「預覽文件」，再從預覽視窗列印。

列印紙張選 **100 × 150 mm**，目前建議自訂縮放 **125%**；先確認預覽再印。助手會將新竹物流寄件單預先縮至 80%，配合 125% 列印還原尺寸，避免滿版內容超出紙張。

7-ELEVEN 原單會在背景處理，等待助手完成即可；合併文件成功產生後會自動關閉原單。原始 QR 圖片在本機擷取，按訂單編號與裝箱單配對。不同來源版面會保留圖片長寬比例，較大的原單等比例縮小至 100 × 150 mm 內，較小的維持原大小；建議的 125% 列印設定同樣適用。**7-ELEVEN 與其他物流請分開下載。**

選「一般列印」時，仍可使用蝦皮原本的下載方式，但助手不會整理文件。重新整理頁面會清空助手的列印任務。

## 問題或建議

<a href="https://forms.gle/dWHwKoQnWCdBVqPn7" target="_blank" rel="noopener noreferrer">填寫回報表單</a>，簡單說明操作步驟即可，也可選填圖片或影片（最多 5 個，每個 100 MB）。

表單須登入 Google；上傳並提交附件時，Google 會記錄帳戶名稱、信箱與相片。截圖、影片請先遮住買家姓名、電話、地址等個資。

目前仍在測試，第一次使用請少量試印，確認訂單、商品內容與列印尺寸。

### 錯誤回報

失敗任務會顯示 Google 表單回報連結與「查看錯誤詳情」按鈕。點開視窗後可複製版本、失敗時間與階段、錯誤堆疊、文件大小與頁數、裝箱單辨識結果，再貼到回報表單。若無法自動複製，視窗會選取全文供手動複製。原始文件下載連結仍保留。

全家原單以背景分頁開啟，畫面保留在蝦皮出貨頁。全家會在本機讀取原生寄件單圖片內的 QR 訂單編號，裁開已驗證的四格版型，再與裝箱單逐筆配對。全家與其他物流請分開下載；不明版型、QR 無法辨識或訂單不符時停止產生，保留原單供核對。合併文件使用 100 × 150 mm，沿用 125% 列印設定。全家頁面需允許 `api.sls.shopee.tw` 的 `/api/logistic/familymart/shipping_label` 路徑。

物流辨識直接讀取「下載出貨文件」上方目前選取的「物流方式」。任務名稱、7-ELEVEN／全家文件流程與新竹物流排版皆使用下載當下的選項，不從買家、商品或訂單列文字推測；選到「其他寄送方式」時不啟動助手任務、不自動調整列印格式，顯示未支援提示並保留蝦皮原生下載。無法讀取選項時也保留原生下載並顯示提示。
