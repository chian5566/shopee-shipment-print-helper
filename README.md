# LEISURE HOMME 出貨印單助手

幫蝦皮賣家把同一筆訂單的寄件單與裝箱單排在一起，方便列印、包貨。

**完全免費，以後也不會收費。目前僅支援熱感列印。**

## 安裝

1. 在本專案頁面點選 **Code → Download ZIP**，下載後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions/`，開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」，選擇解壓縮後的資料夾（裡面要有 `manifest.json`）。
4. 重新整理蝦皮頁面，即可使用。安裝後請保留這個資料夾。

更新時，換成新版檔案，到同一個擴充功能頁面按助手的重新載入按鈕，再重新整理蝦皮頁面。

## 使用

1. 前往蝦皮 [批次出貨 → 下載出貨文件](https://seller.shopee.tw/portal/sale/mass/ship?mass_shipment_tab=301)。
2. 點「印」字圖示開啟助手，確認要出貨的訂單（助手會先選取目前頁面的訂單）。
3. 同時勾選「寄件單」與「裝箱單」，寄件單選「熱感列印」。
4. 按蝦皮的「下載所選文件」。
5. 助手顯示「文件已完成」後，按「列印」。

列印紙張選 **100 × 150 mm**，目前建議自訂縮放 **125%**；先確認預覽再印。

選「一般列印」時，仍可使用蝦皮原本的下載方式，但助手不會整理文件。重新整理頁面會清空助手的列印任務。

## 問題或建議

[填寫回報表單](https://forms.gle/dWHwKoQnWCdBVqPn7)，簡單說明操作步驟即可，也可選填圖片或影片（最多 5 個，每個 100 MB）。

表單須登入 Google；上傳並提交附件時，Google 會記錄帳戶名稱、信箱與相片。截圖、影片請先遮住買家姓名、電話、地址等個資。

目前仍在測試，部分店家的商品貨號或物流格式可能不適用。第一次使用請少量試印，確認訂單與商品內容。
